# ハッカソン 事前練習リポジトリ

当日と同じ流れ（**AIに指示を読ませて → 作業させて → 自分のブランチに提出する**）を、一度体験するための練習場所です。
所要時間は15〜20分ほどです。

## やること

1. このリポジトリを clone し、VS Code で開く
2. Codex（または Claude Code）に、次の1行を送る（`suzuki` は自分のブランチ名に、`〇〇` は自分の GitHub ユーザー名に変える）

   ```
   odai.md を読んで、その通りに謎を解き、成果物を作って、ブランチ「suzuki」に push してください。私の GitHub ユーザー名は「〇〇」です。
   ```

3. AI が許可を求めてきたら、`git` の操作なら許可する
4. GitHub の画面で、自分のブランチに `submissions/【自分のブランチ名】.html` が入っていれば完了

提出状況は運営が GitHub 上で確認します。

## 注意

- **このリポジトリは公開されています。** 名前は名字だけにし、メールアドレスや社内の情報は書かないでください
- main ブランチには push しないでください
- 他の人のブランチには触らないでください
- 困ったら、エラー画面を AI に見せて「どうすればいい？」と聞いてください。それでも解決しなければ運営まで
